## 📖 文档说明

### morning-checklist.md

- **内容**：DBA 每日早晨巡检操作清单
- **涵盖范围**：
  - 系统层面（CPU、内存、磁盘、I/O）
  - MySQL 服务状态
  - 性能指标（连接数、慢查询、缓冲池）
  - 复制状态（主从延迟、线程状态）
  - 备份状态
  - 安全与权限
- **使用方式**：上班后 30 分钟内按清单逐项检查

### monitoring-thresholds.md

- **内容**：MySQL 核心监控指标阈值参考表
- **涵盖范围**：
  - 性能指标（QPS/TPS/缓冲池命中率）
  - 连接与线程
  - 复制与高可用
  - 存储与磁盘
  - 慢查询与 SQL
  - 锁与死锁
  - 错误与告警
- **使用方式**：配置监控系统时的阈值参考，故障排查时的判断依据
